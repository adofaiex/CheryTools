# Chery Tools

**Chery Tools** 是一款针对《冰与火之舞》（A Dance of Fire and Ice, 简称 ADOFAI）的多功能增强模组。
模组提供了一系列在游玩和打谱时的高级自定义功能，包括可视化按键反馈、屏幕叠加信息展示、游戏视觉调整以及旧版由于官方更新引起的谱面修复

## 主要功能 (Features)

### 1. 进阶按键显示系统 (KeyViewer & KeyRain)
高度可自定义的屏幕按键显示工具
* 支持多种不同键位的布局模式（4键、8键、12键、16键）。
* 实时显示游玩时的和总按键次数
* 自由设定外观：大小、边框、透明度、字体、单独调整文本和计数器的位置、背景/边框/文字的按下变色特效
* **雨滴特效 (Key Rain)**：按下按键时候，产出键雨
* 内置 **FreeMake 编辑器**：可在游戏内可视化自由拖拽、排版和设置每个按键的外观属性和层级

### 2. 屏幕叠加信息展示 (Overlayer System)
允许玩家在屏幕任意位置添加自定义的游玩数据文本或装饰图片
* **数据文本层**：使用富文本和变量标签
* **图片层**：支持在游戏上面板叠加自定义图片
* 支持动画系统 

### 3. 游戏视觉调整 (Visual Tweaks)
允许自定义游戏运行时的常见视觉元素
* 隐藏原版关卡名称 (Hide Native Level Name)。
* 自定义红、蓝、绿三种星球及尾迹的颜色。

### 4. 实用工具与修复 (Fixes & Utilities)
* **Legacy Pause 修复 (`EnableLegacyPauseFix`)**：针对游戏官方大更新后更改了“暂停拍”计拍方式（变为n-1）导致旧谱面全盘错位的问题。本功能强制接管/修复过往的谱面解析逻辑，重排老谱面的暂停节奏，使旧谱面能在最新版正常游玩。
* **限制输入 (Limit Input)**：限制防止某些多余按键干扰。

## 安装指南 (Installation)

1. 确保已安装 **UnityModManager (UMM)** 并正确配置 ADOFAI 游戏目录。
2. 下载最新版本的 `CheryTools` 压缩包。
3. 将压缩包拖入 UMM 的 Mods 界面
4. 启动游戏，按下默认呼出组合键 (通常是 `Ctrl + F10`) 即可在 UMM 菜单中看到 Chery Tools，也可以使用快捷键 `Insert` 呼出本 Mod 专属的 ImGui 设置界面。

## 设置与使用 (Usage)
* 在游戏内按下键盘的 **`Insert`** 键可切换出可视化的配置菜单以进行 KeyViewer, Overlayer 等外观的深度定制。
* 可在编辑器模式下，使用鼠标拖拽来调整显示部件的位置与大小。
